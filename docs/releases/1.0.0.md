## Release notes

Launch readiness: accurate titles, sharing previews, and search-engine files.

- Every page has its own title, description, canonical address, and sharing preview.
- A sitemap listing exactly the published pages, and robots rules pointing to it.
- The site's address comes from one setting, so a build cannot point to a wrong or local
  address.
- Case-study wording corrected where it went beyond the reviewed evidence.

1.0.0 is the first public release and includes everything since 0.1.0: the Systems Lab design
(0.4.0); the Probe, Ask the lab, motion with a pause control, the first-visit entrance, and the
message form (0.5.0); the professional profile and changelog (0.3.0); four evidence-traced case
studies (0.2.0); and the foundation (0.1.0). See `/changelog` on the site.

## Checks (pre-candidate, 2026-10-26)

All on the uncommitted release candidate; they become final when re-run on the tested commit.

- Lint, types, and production build pass.
- Browser suite 22/22: every page loads directly; 404 for unknown and draft addresses; no
  overflow at 390, 768, and 1440 px or emulated 200% zoom; every interactive element reachable
  by keyboard with a visible focus indicator; reduced motion and no-JavaScript keep all content.
- Automated accessibility: 0 axe violations on 20 page/width runs; text contrast lowest 5.52:1.
  This is automated checking plus manual review, not a conformance claim.
- Metadata, sitemap, robots, and sharing image match the contract; no draft or private
  content in served files.
- Lighthouse (simulated, localhost): homepage mobile 95, desktop 100; case study mobile 97,
  desktop 100; layout shift at most 0.025.

## Known limitations

- Not tested with a screen reader, in Firefox or Safari, or on real devices.
- Zoom checks emulate 200% by viewport width rather than the browser zoom setting.
- Performance is simulated on localhost (no network or CDN); mobile LCP is about 2.6 s.
- No live demo link (the Resume Analyzer demo has not had an approved end-to-end test).
- No project screenshots; the case studies use labeled explanatory diagrams.
- No `favicon.ico`; browsers use the SVG icon.
- On phones the docked Probe button can sit over a line of text until the page is scrolled.
